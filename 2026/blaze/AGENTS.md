# Agent and contributor notes

This repo encodes **project-specific** conventions in **Cursor rules** under [`.cursor/rules/`](.cursor/rules/). Those files are the source of truth for structure, Mantine usage, TypeScript/ESLint/Prettier, GraphQL codegen, testing, security/env, URL state (nuqs), accessibility, errors/empty states, and feature-flag patterns.

When editing code here, follow those rules together with **`TECH_STACK.md`** and existing patterns in `app/` and `shared/`.
